# تطبيق المستخدم - M Store

## نظرة عامة
تطبيق Flutter متعدد اللغات (العربية والإنجليزية) يوفر خدمات متنوعة للمستخدمين.

## الميزات الرئيسية

### 1. نظام المصادقة
- تسجيل الدخول
- إنشاء حساب جديد
- إدارة الملف الشخصي

### 2. الشاشة الرئيسية
- عرض المنتجات المتاحة
- البحث والتصفية
- إضافة المنتجات للمفضلة

### 3. طلبات الجملة
- نموذج طلب شحنة جملة شامل
- حقول: اسم المنتج، الكمية، الوصف، صورة المنتج
- متابعة حالة الطلب

### 4. خدمات التوصيل (جديد)
- نموذج طلب توصيل شامل
- حقول: نوع البضاعة، الوزن، المكان، الوصف، صورة الشحنة
- متابعة حالة طلب التوصيل

### 5. الخدمات الأخرى
- تحويل رصيد
- شحن كروت ألعاب
- خدمات إضافية

### 6. إدارة الطلبات
- عرض جميع الطلبات
- تصفية حسب الحالة
- محادثة مع الإدارة

## البنية التقنية

### الملفات الرئيسية
- `lib/main.dart` - نقطة البداية والتوجيه
- `lib/core/theme/app_theme.dart` - إعدادات التصميم
- `lib/core/services/supabase_service.dart` - خدمات قاعدة البيانات

### الشاشات
- `lib/presentation/screens/` - جميع شاشات التطبيق
- `lib/presentation/screens/delivery_services_screen.dart` - شاشة خدمات التوصيل الجديدة
- `lib/presentation/screens/store_screen.dart` - شاشة طلبات الجملة

### النماذج
- `lib/presentation/screens/order_model.dart` - نموذج الطلب مع دعم أنواع مختلفة

## كيفية الاستخدام

### شاشة خدمات التوصيل
1. انتقل إلى "خدمات أخرى" من القائمة السفلية
2. اختر "خدمات التوصيل"
3. املأ النموذج بالمعلومات المطلوبة:
   - نوع البضاعة
   - وزن الشحنة
   - مكان الشحنة
   - وصف الشحنة
   - صورة الشحنة (اختياري)
4. اضغط "إرسال طلب التوصيل"
5. تابع الطلب من شاشة "طلباتي"

### شاشة طلبات الجملة
1. انتقل إلى "بيع الجملة" من القائمة السفلية
2. املأ النموذج بالمعلومات المطلوبة:
   - اسم المنتج
   - الكمية المطلوبة
   - وصف المنتج
   - صورة المنتج (اختياري)
3. اضغط "إرسال طلب الشحنة"
4. تابع الطلب من شاشة "طلباتي"
