# ميزة تحويل رصيد الجوال

## نظرة عامة
تم إضافة ميزة تحويل رصيد الجوال إلى التطبيق، والتي تسمح للمستخدمين بشراء باقات رصيد متنقلة من مختلف المشغلين.

## الملفات المضافة/المحدثة

### ملفات جديدة:
1. `mobile_package_model.dart` - نموذج البيانات للباقات المتنقلة
2. `mobile_credit_screen.dart` - شاشة تحويل رصيد الجوال

### ملفات محدثة:
1. `order_model.dart` - إضافة نوع طلب جديد `mobileCredit`
2. `orders_screen.dart` - دعم عرض طلبات الرصيد
3. `order_chat_screen.dart` - دعم محادثات طلبات الرصيد
4. `other_services_screen.dart` - إضافة رابط لصفحة تحويل الرصيد

## الميزات

### 1. عرض الباقات
- عرض باقات SyriaTel و MTN Syria والمشغلين الآخرين
- تصفية الباقات حسب المشغل
- عرض السعر وقيمة الباقة

### 2. إضافة للطلبات
- إضافة الباقات إلى قائمة الطلبات المؤقتة
- عرض تفاصيل الباقة في نافذة منبثقة
- التحقق من عدم تكرار الباقة

### 3. إدارة الطلبات
- عرض طلبات الرصيد في شاشة الطلبات
- تمييز طلبات الرصيد بلون وأيقونة خاصة
- دعم المحادثات لطلبات الرصيد

### العناصر:

- بطاقات بيضاء مع ظلال خفيفة

## الخطوات المستقبلية

1. **ربط قاعدة البيانات**: استبدال البيانات الوهمية ببيانات حقيقية من قاعدة البيانات
2. **إضافة المزيد من المشغلين**: دعم مشغلين جدد
3. **إضافة أنواع باقات جديدة**: باقات بيانات، باقات مكالمات
4. **إضافة نظام الدفع**: ربط مع بوابات الدفع
5. **إضافة إشعارات**: إشعارات عند معالجة الطلب

## الاستخدام

1. انتقل إلى "خدمات أخرى" من القائمة الرئيسية
2. اختر "تحويل رصيد الجوال"
3. اختر المشغل المطلوب من شريط التصفية
4. اضغط على "إضافة لطلباتي" للباقة المطلوبة
5. انتقل إلى "طلباتي" لتأكيد الطلب
6. ابدأ المحادثة مع الإدارة لمتابعة الطلب
